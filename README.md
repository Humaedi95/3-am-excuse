# The 3 AM Excuse

One line, in the voice of a hardware wallet refusing to sign a transaction at 3 AM. The wallet is a night-shift worker with a rota: its shift ends at midnight, and the 3 AM hours belong to the owner's future self — who has already filed a complaint about half-asleep signing.

## Run

```sh
python3 main.py
```

The program writes the entry line to `/output/entry.txt`.
